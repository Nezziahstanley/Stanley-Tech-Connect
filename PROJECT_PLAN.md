# STANLEY TECH CONNECT

## Project Title

Stanley Tech Connect

## Project Purpose

Stanley Tech Connect is a technology-focused platform designed to help individuals learn practical technology skills through courses, mentorship, project-based learning and community activities.

## Problem Statement

Many people want to learn technology but struggle to find structured practical training, mentorship, projects and a supportive community in one place.

Stanley Tech Connect aims to provide a platform where learners can access technology-related learning opportunities, participate in projects and challenges, and connect with the STC community.

## Target Users

1. Visitors
2. Students/Members
3. Administrators

## Main Features

1. User Registration
2. User Login
3. User Dashboard
4. User Profile
5. Courses
6. Course Enrollment
7. Services
8. 30-Day Challenges
9. Contact System
10. Admin Dashboard
